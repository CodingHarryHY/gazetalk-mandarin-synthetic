# ADR-0001: Isolated scope and evidence boundaries

- Status: accepted
- Proposed date: 2026-09-29, Europe/Copenhagen
- Accepted date: 2026-09-29, Europe/Copenhagen; exact approval time not recorded
- Author: Codex implementation assistant

- Supersedes: none

## Context
The user requested a Mandarin localization of the report baseline, with no training
or deployment. The available checkout omits the local reference preprocessing and
full persona-construction pipeline described in the report.

## Decision
Use an isolated mandarin package and fictional rule-based inputs. Do not add a
restricted-data importer, retrieval of patient examples, population ratios, model
training, or deployment. Mark all runs not_calibrated and permission status
not_determined. Keep root and v2 code untouched.

## Alternatives considered
Reusing the same Python package name could cause import collisions. Importing
restricted data would require a separate authorized design. Treating the English
distribution as Mandarin evidence would be unsupported.

## Consequences, evidence limits, and reconsideration
This is a functional engineering prototype with literature-informed assumptions.
Small real corpora may still be useful later, but no real-corpus agreement can be
reported now. Reconsider when governed aggregate features and task-matched review
become available.
