# ADR-0009: Evidence-linked and observable profile guidance

- Status: accepted
- Date: 2026-10-01, Europe/Copenhagen
- Author: Codex implementation assistant
- Requester: project owner, asking for evidence mapping, observable guidance, and independent output review without restricted-corpus comparison
- Affected version: 0.1.3
- Supersedes: none; refines the authored profile descriptions of ADR-0002
- Sources: source register and profile-evidence.md

## Context and decision

The 0.1.2 `profiles.json` combined recognizable subtype contrasts with
unquantified frequency words and text-only representations of speech phenomena.
The source register did not map individual behaviour fields to evidence. The
completed 12-dialogue pilot gives a small baseline for reviewing generated
surface language, but has one persona per profile and no clinical assessment.

Keep the existing six profiles, nine behaviour fields, schema, severity bands,
and generation architecture. Revise behaviour strings to conditional,
observable tendencies, with explicit limits on repetition testing, fabricated
Chinese spellings, and per-turn symptom requirements. Add a field-by-field
evidence register and a reproducible text-only review rubric with a review of
the previous pilot. Add published Chinese classification and public subtype
sources to the source register. Preserve the old run bundle unchanged and use
fresh 0.1.3 run directories.

## Alternatives considered

Mandatory symptom counts would create artificial dialogue and imply unsupported
rates. Reconstructing speech-sound errors from Chinese text would claim
information the modality does not contain. A clinician label or classifier score
from generated text alone would overstate clinical validity. Direct comparison
with restricted Mandarin transcripts is outside the requested scope.

## Consequences and validation

New persona fields and prompts will differ from 0.1.2, so old runs cannot be
resumed under this catalog. The evidence mapping records background support and
unverified author choices; it does not establish Mandarin subtype frequencies.
Offline tests verify that all six generated personas retain the schema and the
revised guidance reaches the request. New generated output requires separate
review with the documented rubric before quality conclusions are drawn.
