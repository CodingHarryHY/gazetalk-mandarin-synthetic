## Context
The first version must export CHAT and manual review tables. The existing English
CHAT exports split a JSON turn into multiple main tiers, without an included exporter.

## Decision
Keep JSONL authoritative. Export text-only orthographic CHAT, a reversible source
turn map, English review metadata, Chinese utterances, and unfilled review fields.
Use output-addressed export directories so repeated export preserves manual edits.
Distinguish internal structural checks from official external CHAT validation.

## Alternatives considered
One CHAT row cannot always be equated with one JSON turn. Inventing timed pauses,
audio references, or clinical annotations would misrepresent the source. Automatically
filling plausibility ratings would imply unavailable expert evidence.

## Consequences, evidence limits, and reconsideration
CHAT text is not word-segmented or MOR-ready. Punctuation and reserved characters
are normalized with original text preserved in the map. An independent CLAN/Chatter
check remains pending until actually run. Review flags are not clinical findings.
CSV generation is application code using the standard library, not workbook authoring.
