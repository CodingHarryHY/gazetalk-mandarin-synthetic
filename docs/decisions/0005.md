## Context
After approving the plan, the user required all auxiliary information, documentation,
code, and comments to be English. Dialogue content remains Chinese.

## Decision
Write prompts, persona descriptions, topic/strategy values, logs, review labels,
documentation, and comments in English. Prompts request Simplified Chinese dialogue.
Allow Chinese only in generated or fixture utterances and necessary language
processing literals. Keep metadata distinct from quoted dialogue content.

## Alternatives considered
A translated Chinese prompt or Chinese persona labels would violate this additional
requirement. Storing only English dialogue would violate the dataset goal.

## Consequences, evidence limits, and reconsideration
Catalogs have an ASCII guard in v0.1 to catch accidental Chinese metadata.
This is stricter than general English typography and can be revised if needed.
Tests verify English persona values and request instructions. Future decisions
and version notes must follow the same policy.

in tests/test_pipeline.py. Actual execution timestamps, requests, and hashes
