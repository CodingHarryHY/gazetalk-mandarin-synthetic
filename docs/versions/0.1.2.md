## Change and rationale

See ADR-0008. Optional generation.api_key overrides OPENAI_API_KEY when nonempty.
An absent, empty, or whitespace-only value falls back to the environment. Neither
source is required for offline persona preparation. Credentials are passed only
to the SDK constructor and excluded from the archived effective configuration,
fingerprint, repr, and generation request bodies. Configuration errors do not echo
input values. The original TOML file still contains the configured plaintext key.

Updated files: config.py, clients.py, generate.py, test_pipeline.py, both run TOMLs,
package version metadata, README, changelog, and the decision/version archives.
The local pilot endpoint http://127.0.0.1:8317/v1 was preserved. Empty api_key fields
were added for the owner to fill. Default run directories are pilot_v0_1_2 and
batch_2000_v0_1_2; existing runs were not modified or regenerated.
